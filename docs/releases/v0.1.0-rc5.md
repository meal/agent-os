## What v0.1 does

A controller runs a coding agent against a repository under a signed-off task contract.
Every side effect is journaled as intended, dispatched, executed, published and committed,
so a killed controller resumes without repeating a completed effect. Every authority is a
revocable capability handle checked by a broker. A task succeeds only through a protected
verification of exactly the final workspace. Effects run on the host or, jailed, in one
Firecracker microVM each, with contract-driven vCPU, memory, disk and I/O limits. The agent
is a deterministic patch agent or the Anthropic model with five tools. An optional
WebAssembly analyzer reads the snapshot through broker-checked reads and exports a report
that never counts as verification.

## Known limits

- The fresh-host gate ran in a fresh container on the only KVM host available, not on a
  separate machine.
- One model provider; x86_64 Linux only; the jail needs root and delegable cgroup v2.
- The host worker is not sandboxed.
- The analyzer's report is not shown to the agent.
- The work lives on the `acceptance-evidence` branch, unmerged; the manual KVM and live
  GitHub workflows run only on `main`.
